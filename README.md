# s-talha.github.io

Source for my portfolio site at **[s-talha.github.io](https://s-talha.github.io/)**.

One hand-written HTML file with no framework or build step. The hero runs a small simulated agent: press **Run again** to switch between a request the agent answers itself and one that business rules send to a person.

- `index.html`: the whole site (markup, styles and script)
- `assets/`: favicon, social preview image, and the Agentdeck demo GIF

Hosted on GitHub Pages from the `main` branch.
